# SA’A Liquid Glass

Read architecture.md for the full visual standard. Primary #FFA64D; dark-blue secondary remains TBD. Use shared semantic tokens and the official asset through Logo. Never fabricate a logo. Heroicons only. Cards are borderless with layered shadows; buttons have smaller radii. Use glass selectively for navigation and floating surfaces; preserve readable content backgrounds. Support small screens, keyboard focus, clear errors, and reduced motion.

The original skills/apple-liquid-glass file is inspiration only: override Apple blue, mandated SF Pro, fixed radii, colorful icons, borders, and MockFlow tooling. Do not install its tooling.
